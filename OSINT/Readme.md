OSINT Projects
This directory contains practical exercises focused on Open Source Intelligence (OSINT), using different tools and techniques to collect, analyze and interpret publicly available information.
Projects
1. GHunt

Investigation of publicly exposed information associated with Google accounts using OSINT techniques.

2. Sherlock

Username investigation across multiple social media platforms and online services.
Objectives
- Understand OSINT methodologies.
- Learn to use different reconnaissance tools.
- Analyze and interpret collected information.
- Document findings and investigation procedures.
Disclaimer
All exercises are conducted in authorized environments, using accounts and data owned by me or explicitly authorized for testing. No unauthorized access or intrusive activity is performed.
